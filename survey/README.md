# Research & Survey

### Responsibility
Proof of the problem. This folder stores the evidence that makes the "Knowledge Mirror" an urgent necessity.

### Sub-Directories
- `data/`: Anonymized raw results from the 96-student survey.
- `analysis/`: Statistical calculations and pitch-ready metrics (e.g., "72% of students...").

### Data Privacy
- **DO NOT** commit personally identifiable information (PII).
- All data must be anonymized before being added to this repository.
