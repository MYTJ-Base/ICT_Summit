# Web Interface (The Mirror)

### Responsibility
The visual and interactive layer of the project. This is where the student "sees" their knowledge.

### Components
- `components/`: UI elements (sliders for CDS, cards for KB).
- `viz/`: The knowledge graph visualization (D3.js / Sigma.js).

### Standards
- **Interaction:** Communicates with the `src/` backend via API or structured JSON files.
- **Aesthetics:** Must be high-fidelity for the competition demo.
