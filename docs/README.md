# Documentation (The War Room)

### Responsibility
The central repository for project strategy, architectural vision, and team governance.

### Sub-Directories
- `architecture/`: Deep technical specs for the KB Graph and the 8-axis CDS model.
- `strategy/`: Competition positioning, SWOT analysis, and business model drafts.
- `team/`: Legal and collaboration documents (IP agreements, role definitions).

### What NOT to put here
- No source code.
- No raw survey data (use `survey/data/`).
- No pitch scripts (use `pitch/script/`).
